# CLAUDE HERÓI 🎸

Jogo de ritmo de guitarra (5 pistas) com importação de MP3, feito em HTML/CSS/JS puro. Funciona no celular e instala como app (PWA).

## Como publicar no GitHub Pages (pelo celular)
1. No GitHub, crie um repositório (ex.: `claude-heroi`).
2. Envie TODOS os arquivos deste projeto para a raiz (o `index.html` precisa ficar na raiz).
3. Vá em **Settings → Pages**.
4. Em **Source** escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
5. Aguarde ~1 minuto e abra `https://SEU-USUARIO.github.io/claude-heroi/`.
6. No Chrome do Android: menu ⋮ → **Instalar app**.

> Ao atualizar o jogo, altere `VERSION` em `sw.js` (ex.: `ch-v2`) para o celular baixar a versão nova.
